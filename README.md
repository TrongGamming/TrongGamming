## What I'm up to

- Writing an AutoCAD add-on in C++20, MFC and ObjectARX ([RebarInsight](https://github.com/TrongGamming/RebarInsight)).
- Remaking Ultima Online in C++20 and SDL3 to get a feel for game loops, networking and memory management.
- Building a map-based web app (Django REST + Next.js) for a GIS course project.
- Looking for a backend or C++ internship.

## Stack

C++, Java, C#, Python, JavaScript/TypeScript. Spring Boot, ASP.NET Core, Django, Node.js, React/Next.js. MySQL, SQLite, SQL Server, PL/SQL.

## Projects

- **[RebarInsight](https://github.com/TrongGamming/RebarInsight)**: AutoCAD add-on that extracts rebar quantities from drawings and exports to Excel. C++20, MFC, ObjectARX, CMake, GoogleTest.
- **[Ultima-Online-Remake-CPP](https://github.com/TrongGamming/Ultima-Online-Remake-CPP)**: multiplayer remake of Ultima Online, also builds for Android. C++20, SDL3.
- **[SpringBoot-Warehouse-Management-System](https://github.com/TrongGamming/SpringBoot-Warehouse-Management-System)**: stock, branches and role-based access. Spring Boot, MySQL.
- **[gis-oss](https://github.com/TrongGamming/gis-oss-backend)** ([frontend](https://github.com/TrongGamming/gis-oss-frontend)): store management on a map. Django REST, Next.js.
- **[ManangerDish](https://github.com/TrongGamming/ManangerDish)**: real-time table ordering for restaurants. ASP.NET Core, SignalR.
- **[OrderManager](https://github.com/TrongGamming/OrderManager)**: order and delivery API. Express, Sequelize.
- **[CPP-Data-Structures-Algorithms](https://github.com/TrongGamming/CPP-Data-Structures-Algorithms)**: DSA exercises, with data structures written by hand instead of using the STL.
